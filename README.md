Идея и механика
Сверху экрана падают фрукты трёх видов: 🍎 яблоки, 🍊 апельсины, 🍇 виноград. Игрок двигает корзину влево-вправо и ловит только тот фрукт, который указан в розово-фиолетовой полосе «Собирай». Нужный фрукт меняется каждые 7 секунд.
Поймали нужный фрукт — плюс 1 очко.
Поймали не тот фрукт — минус 1 жизнь.
Фрукт, упавший мимо корзины, — без штрафа.


Управление
Клавиатура: ← / → или A / D
Мышь / тачскрин: двигайте корзину указателем или пальцем по игровому полю
Технологии
Игра сделана на чистых HTML, CSS и JavaScript, без сборщиков и библиотек. Музыка и звуки ловли фруктов генерируются в реальном времени через Web Audio API — отдельные аудиофайлы не нужны.
